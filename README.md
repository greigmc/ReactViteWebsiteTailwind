## Prerequisites

- **Node.js** (v16 or later)
- **npm** (v7 or later) or **yarn**

## Installation

1. **Clone the Repository**:

   ```bash
   git clone https://github.com/greigmc/ReactViteWebsiteTailwind.git
   cd reactvitewebsiteTailwind
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

## Running the Application

```bash
npm run dev
```

## Test the Application with Jest

```bash
npm run test
```
